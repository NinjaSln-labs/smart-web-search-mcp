快速开始 / Quick Start

# 安装（零 Python 依赖；MCP server 需 Node ≥ 22.7）
uv tool install smart-web-search-mcp

# 探测本机 agent（只读）→ 一键写入 MCP 配置（幂等）
smart-web-search-install --list
smart-web-search-install

# 完成后 pi / Cursor / cline / opencode / zcode / Qoder / mcode
# / commandcode / dsh / reasonix 里即出现 smart_web_search 工具

路由模型 / Routing

L1  wigolo (stdio, 18 引擎, 免费) + keenable (HTTP, 免费层)   并行
L2  tinyfish (wallet 计费) → tavily (1000 次/月免费)           串行
L3  serper (Google; 2500 一次性免费)                           无条件兜底

每次调用返回完整 routing chain——LLM 可感知是哪一层接住的。

特性 / Features

🧭 梯次降级

免费层并行打头，钱包层串行补位，付费层只兜底。LLM 只见 1 个工具，复杂度全在路由内。

📦 零依赖

安装器纯 Python 标准库；MCP 核心是 Node ≥22.7 strip-only 直跑的 TS——免 esbuild、免打包。

🤝 一键接入 10 家 agent

pi / Cursor / cline / opencode / zcode / Qoder / mcode / commandcode / dsh / reasonix；自动探测、幂等写入、覆盖前备份。

🔁 spawn-per-call

每次 tools/call 独立子进程跑完整搜索后退出——跨调用零状态累积，升级不失效。

🪫 429 自感知

keenable 公共层 429 自动落节流标记，60s 冷却内跳过，pi / CLI 双路一致。

📊 可观测

每次搜索的完整 chain 逐条落盘 JSONL（SMART_WS_LOG_RAW=0 可剥 raw_text），路由调优有据可依。

🔑 凭据单源

env / config 文件一处配置，各 agent 共享；无 key 时免费层开箱即用。

🖥 跨平台

Windows / macOS / Linux；双 framing（LSP 头式 / 裸 JSON 行式）自适应各类 stdio 实现。
